# 8000/9000复评结论

核验四组补评全部完成；三个候选各seed42/43/44共384回合，策略均值动作、环境随机化保留，权重未变且任务源码匹配。

成功率优先时推荐model8000作为当前候选：354/384=92.19%，9000为343/384=89.32%，9997为339/384=88.28%。8000三个seed分别92.19/93.75/90.62%，均超过另外两模型，非单seed偶然最高。比9000多11成功回合（2.86个百分点），比9997多15回合（3.91个百分点）；有限样本仍不能证明所有随机条件下必然最好。

完整松爪且严格落座：8000 345/384=89.84%，9000 332/384=86.46%，9997 330/384=85.94%。8000平均P95、采样接触峰值及动作饱和率也在三者中最低，优势不仅是成功计数。8000倾角峰值15.20度高于9000的6.97度；9997速度峰值38.06mm/s低于8000的49.68mm/s，不能称8000所有稳定性指标最优。

8000失败30回合，其中8浅插、22其他失败；不能仅凭失败总数推出具体根因。三模型均无越界/夹宽失败。成功与超时可能重叠。此前建议优先补9000基于单seed运动指标；这次多seed数据按用户成功率优先标准支持改选8000。建议下一步8000 GUI验证与大倾角轨迹检查，再决定真机迁移；不自动续训、不替换real_test中的2999交付包。原模型全部保留。
