# model8000 GUI验证与历史30次失败诊断

2026-10-02。实际启动GUI：4环境×前4回合、seed42、均值策略、随机化保留。15/16成功且完成松爪严格落座，1超时、0越界/夹宽失败。平均回合P95 2.13N，接触采样峰值6.31N，评估193.61秒。失败env0第1个配额回合终局深度0.032mm、XY5.407mm、倾角0.288度。GUI新样本与历史384回合分开；没有录制视频，也未声称人工观看了屏幕动画。结论来自GUI运行日志及历史控制轨迹。

历史口径：seed42/43/44各32环境×前4回合，384回合，354成功30失败。env_id从0计，episode为每环境配额回合1–4。入孔代理=深度>=2mm且XY<=13mm，分析只看运动启用且未释放阶段。

## 22次未入孔失败

全程均未达到入孔代理条件。最终SEARCH12次、PROBE10次、INSERT0次。终局XY中位6.99mm（1.20–15.59），深度中位0.013mm。末5秒净进深中位-0.001mm，XY接触中位0.091N，|Z|接触中位2.492N；向下指令中位2.413N，XY指令中位0.279N。每回合PROBE返回SEARCH12–13次，中位13次。轴倾角峰值中位0.338度，无明显歪轴。

证据支持：轴底压在孔口附近但搜索没有有效消除横向偏差，反复锁XY试压消耗时间；不是下压力缺失。在末5秒SEARCH的704采样点中，80.97%两轴Kp*(reference-TCP)均不超过对应死区，XY参考跟踪误差中位1.53mm。由于这是步末采样且有阻尼/限速，不能精确重建物理步力或单独证明死区为唯一根因。真轴底与虚拟TCP末端XY差中位5.83mm，包含初始抓取误差，不可全当作动态滑移。

## 8次浅插失败

首次进入2mm在13.80–19.07秒，全部晚于13秒。最终7次INSERT、1次SEARCH；深度8.97–24.19mm。末5秒净进深中位15.92mm；入孔后最长未创造新1mm纪录均<=1.20秒，未出现长时间彻底停滞。多数属于搜索耗时太长、剩余推进时间不足，而不是旧4900那种长期SEARCH侧向顶压。不能保证延长回合全部成功，尤其2个带较大初始倾角的回合。

## 大倾角

最大值15.198度：seed42 env9 episode4，15.47秒、PROBE、深度3.05mm；最终失败深度11.45mm。运动阶段>5度持续19秒，>10度约11.67秒，不是瞬时尖峰。reset后第一帧0.067秒已经8.878度（相对hand8.954度），轴-base力为0，策略插入尚未启用。此后才进一步增大。终局轴底-TCP横向差20.43mm，指间位置差峰值0.131mm，没有以前厘米级双指不同步。

第二个>5度回合：seed43 env18 episode2，峰值5.95度；第一帧已5.61度，相对hand5.50度，终局24.19mm失败。全384回合只有2个运动阶段峰值>5度、1个>10度。源码reset设置默认轴姿态，未显式采样姿态误差；现有日志最早为16个物理子步之后，无法定位这段时间内是初始穿透、夹爪接触还是其他reset瞬态所致。不能把初始大倾角直接归咎于策略碰撞，也不能断言reset代码有某个已证实bug。

## 建议（未实施）

1. 固定8000做20s与25/30s回合时长对照，观察8个晚入孔回合是否获益。真实回合时间变更需另实验和明确修改评估源版本，不能绕过历史哈希保护。
2. 对未入孔失败，优先验证减轻XY死区或减少重复PROBE打断的单因素对照，不直接继续加下压力。
3. 针对初始大倾角，采集reset后前16物理子步的hand/shaft/finger状态、接触及穿透，再核对真实夹持偏差范围。保留合理不对称/滑移，不将轴焊死或强行每步摆正。
4. 改变回合时间/死区/阶段后先固定策略测试，再决定是否微调。现有证据尚未验证任何改动带来的因果改善。
