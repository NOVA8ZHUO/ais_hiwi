# 实验记录要求

用户要求从2026-09-28起持续记录训练指标及奖惩/控制调整。修改奖励、控制、随机化、观测、动作、终止条件或PPO配置时，必须同步更新 `docs/EXPERIMENT_CHANGELOG.md`，写明动机、参数前后值、验证结果和未验证事项。

通过 `scripts/train.py` 运行实验以保留自动归档；保留原始TensorBoard事件、配置、逐回合CSV及检查点。分析历史实验时使用其实际配置和日志，不能把当前源码当作历史源码。已存在实验可以用 `scripts/archive_experiments.py` 补导指标，但应明确无法追溯恢复的数据。

区分训练探索轨迹、零残差基准、确定性检查点回放；不得把三者成功率直接混为一个指标。指标不足时明确证据边界，避免仅凭reward增加宣称插入改善。
