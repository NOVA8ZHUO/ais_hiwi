# XY搜索诊断：218 GUI六个失败回合

只读分析当前代码及`20260929_135928_model218_seed43_control_trace.csv`，未修改控制/奖励或运行新仿真。

当前孔估计误差每回合独立均匀采样XYZ各±10 mm，回合内固定；物理Base/孔不移动。XY误差向量最大约14.14 mm，XYZ最大约17.32 mm。另有抓取手掌系X±8/Z±5 mm、Y采样0，不能将孔估计误差当作实际轴底总误差。Y采样为0不代表接触后两指/零件绝不会横移。

## 已确认

六个失败回合，去除最初1秒后共有19秒：SEARCH累计9.73–10.93秒，PROBE累计8.07–9.27秒，占42–49%；每回合SEARCH→PROBE为11–13次，PROBE→SEARCH为11–12次，没有进入INSERT。根据代码，PROBE锁XY/yaw，0.8秒无进展返回SEARCH，冷却0.4秒，Fz≥1 N连续两帧可再次试压。因此确实存在周期性暂停横向搜索；是否改变阈值可提高成功率还需对照，不能直接作因果保证。

策略XY并非恒定：失败回合X动作大致覆盖−0.61至+0.18，Y约−0.57至+0.12。累计TCP XY路程36–60 mm，轴底XY路程32–54 mm；路程不等于朝向孔口的有效进展。SEARCH时参考到实际TCP的XY误差P95为4.50–10.68 mm，平均XY命令力0.16–0.47 N。

世界坐标下末态轴底与TCP的XY差14.0–18.8 mm。进一步将相对向量转换到每帧hand坐标系，去除手腕旋转影响后，六个失败回合从夹持等待结束到回合结束的相对XY变化为13.95–16.67 mm，主要发生在hand Y。轴向Z变化仅约0.05–0.14 mm。两指位置差的一半所代表的夹持中心移动量约14.02–16.47 mm，与零件hand Y运动幅度接近。

因此夹持中心相对hand大幅漂移有较强证据，不能全解释为抓取初始随机误差、手腕转动或轴向打滑。固定虚拟TCP不能继续准确表示真实轴底；夹宽正常并不排除这一问题。是否超出真机实际允许漂移需实测比较，不能强制修成永远居中。

## XY死区：配置可疑，但旧日志不足以定量归因

每轴XY弹簧项dead_zone=sign(F)*max(abs(F)−d,0)，d每回合随机0–5 N，Kp随机400–800 N/m；阻尼不经过死区，Z也不经过。最大死区对应约6.25–12.5 mm单轴静态位置偏差才开始产生弹簧驱动，已经与当前孔估计误差量级相近。

旧trace没有记录每回合Kp、deadzone以及死区前后弹簧力，不能由控制步末的命令力直接精确反推出死区吞掉比例。低XY力同时受阶段锁目标、阻尼、跟踪速度等影响，不应宣布已证明死区是唯一主因。

## 后续优先级

新证据下，先诊断/校准夹爪中心的动态约束，保留恒力、不对称和真实可接受的滑移；不能继续依赖固定TCP同时允许约15 mm中心漂移而不处理。其次单因素检查PROBE反复锁XY对有效搜索时间的影响。XY死区应在补充Kp/d/死区前后力记录后做开关或减小幅度对照。完成这些检查后再考虑长续训；本次未作修改。
