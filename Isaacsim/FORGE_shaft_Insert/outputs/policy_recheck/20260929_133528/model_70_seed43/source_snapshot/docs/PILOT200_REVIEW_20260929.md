## 后期风险与具体证据

- model_70平均P95力3.02 N、峰值10.11 N，均低于基准；model_218峰值12.85 N高于基准11.22 N。命令力限幅不等于实际碰撞峰值硬上限。
- 夹持阶段倾角超过10°的回合：基准8、70为2、120为7、218为11。超过5°的记录占比：11.1%、8.3%、6.1%、16.3%。因此218倾斜问题比70更频繁，不只是某一个极端峰值。
- 基准54.61°发生于env17第3回合末尾，stage=INSERT，轴底深度约3.79 mm，夹宽仍35.12 mm；它不是松爪后的自由落下。说明夹宽有效不代表轴姿态有效，INSERT也可能在滑移/估计误差后保持错误阶段。
- 218动作饱和主要来自yaw：额外诊断窗口（未释放且t≥1 s）yaw饱和4077个采样，Z为152，XY均0。原平均动作饱和率3.07%的口径略有不同，但定位到yaw很明确。不能笼统地说XY搜索幅度发散。
- 浅插失败2–25 mm：12→9→12→19；218失败中67个终局深度<2 mm、19个浅插。更深探索与浅插卡住可能并存，不能把浅插数量增加单独解释为全面退步。

## reward与学习率

训练mean reward在70/120/218附近为61.99/74.39/78.47，但独立成功率38.3%/25.8%/32.8%，两者并不同步。全程训练累计成功率约20%，最终20.58%，也不是持续接近收敛的曲线。

自适应学习率记录范围约1e-5至1e-2，比初始3e-4上限高约33倍。这是值得控制的潜在更新不稳定因素，不能仅凭相关性认定它导致退步。下一次可在其他配置固定时对照更受限的学习率方案，不应同时更改控制和全部奖励。

现有keypoint/place持续奖励与成功后较快结束存在潜在目标不一致：接近孔口但停留可能累计正回报，prediction误差减少也能使reward增加，而不意味着插入更多。日志支持“reward不是成功率代理”，尚不能证明策略已经主动利用某个漏洞。应比较成功轨迹与停滞轨迹的分项累计奖励后再改。

## 建议顺序

1. 保留70和218，用额外2–3个种子复评，优先确认70的优势与完整释放成功率；不自动追加长训练。
2. 回放大倾角与浅插失败，检查INSERT是否需要在无进展/失去有效接触时退出或恢复搜索，以及夹持滑移造成的虚拟TCP失真；不放宽25 mm任务标准，不强制零件刚性固定。
3. 分开试验：先解决明确控制问题，或在控制不变时限制学习率波动；每项独立记录，不同时堆加惩罚项。
4. 对照成功与停滞回报，必要时使奖励更重视完成流程而不是长时间停在高奖励区域。改环境后需重新建立对应版本基准。

实测训练4160.7秒（约69.3分钟），三次评估合计约40.7分钟，总计约1小时50分钟（不含各进程启动等开销），比此前3–4小时预算快。不能因此直接外推1000轮必然收益更高。
