# 当前任务：插入25毫米后松爪（2026-09-28）

本页覆盖旧文档中“46–48毫米才算插入成功”、10秒最大回合、成功后持续夹紧以及28/52维观测的说明。变化来自用户明确的遥操作任务定义，不是论文原始设置。

## 成功、释放与结束

1. 实际轴底低于目标孔口至少25毫米，即达到插入深度目标。不再要求XY≤0.5毫米或倾角≤5°；这两个量继续作为诊断记录。
2. 为排除孔外掉落，轴底XY需处于目标孔区域（半径13毫米，来自约26毫米孔径）；深度不能超过原越界下界57毫米。这是目标区域检查，不是精密对中门槛。
3. 达到目标后，下一个15 Hz控制步开始松爪，无额外成功持续时间要求。停止下压、保持当前TCP位置/yaw，手指持续开到60毫米；此之前仍持续−20 N闭合。释放是唯一主动停止夹紧的阶段。
4. 释放后观察2秒，以`release_complete`结束回合；若提前出现原越界条件则仍失败。释放阶段免除夹宽失败，因为开爪是预期动作。最大回合20秒（300控制步），超时自动reset。
5. 松爪后是否维持25毫米插入、是否达到47±1毫米深度、是否还满足旧严格落座条件，分别记录，不能混用。

仿真释放触发使用真实轴底几何，属于任务监督。策略没有获得真实轴位姿，但自动释放门槛有仿真特权信息，不能称为已可部署；真机应接入独立深度估计或操作者确认。没有将轴焊接、瞬移、强制两指对称或在线消除抓取误差。

## 为什么之前没有成功

旧47±1毫米判据、零残差、只把10秒延长为20秒的对照中，4/4回合曾完整到位，4/4连续成功至少0.5秒，2/4结束时仍严格成功。首次完整到位出现在10.73–11.73秒，超过旧10秒窗口；末期另2回合XY约0.505/0.599毫米而超过旧0.5毫米阈值。

所以不是完全插不进去。时间不足和末期严格对中判据都影响旧结果；继续强夹下压也不是保持成功的合适方式。此数据在`outputs/insertion_completion/time20.csv`与`time20_analysis.json`，仍属于旧判据，不能混成新的释放成功率。
