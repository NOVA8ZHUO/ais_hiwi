## 1. 用户指定的夹爪参数

| 参数 | 当前设置 | 实现含义 |
|---|---|---|
| 抓取力命令 | 20 N | 每个物理步持续发送闭合驱动力 |
| 预期总开口 | 35 mm | Reset时每指关节17.5 mm |
| 总开口闭合速度 | 20 mm/s | 对称换算为每指10 mm/s的PhysX速度限制 |
| 宽度容差 | ±5 mm | 总开口30–40 mm认为宽度合格 |
| 达到合格宽度后 | 继续闭合施力 | 不撤销闭合命令，也不把轴焊接到夹爪 |

仿真采用每指 `-20 N` 持续闭合力命令和每指20 N effort配置，关闭手指位置PD。
每指速度限制10 mm/s，对应总开口20 mm/s；Reset已经处于夹持状态，不模拟从张开状态抓取。
**持续夹紧保证：reset立即设置闭合力，之后每个240 Hz物理步再次发送闭合力命令。
宽度合格、开口停止缩小、零RL残差、机械臂保持/下插均不会撤销夹紧力。**
宽度判据只用于确认抓取状态，绝不作为“到宽度后停力”的开关。
这不是把 `35 mm` 写成强制位置，也不是把±5 mm作为关节行程限制。
**20 N真机指令与模拟每指接触法向力的精确对应尚未标定**，不能将两个指令值相加后宣称
“真机夹持力为40 N”。PhysX速度限制也不是对碰撞冲量速度的逐时刻硬保证。
如果之后提供实际指尖力/电机映射，再调整这个驱动力映射；目前保留用户指定20 N数值。

默认前0.5秒保持机械臂位置，夹爪持续闭合；这之后宽度合格才开始施加残差和下插目标。
1秒后宽度不合格会结束当前回合并记录 `invalid_grasp_width`。
这些等待时间是工程默认，不是用户测量值或论文参数。
宽度合格不等于已经证明零滑移，测试单独统计轴在夹爪坐标系下的位移。
按用户补充说明，允许合理的接触滑移及插入力引起的转动，不把零滑移作为验收条件。
没有增加轴与夹爪之间的固定连接、轴姿态锁定或额外防滑弹簧；也未采用诊断时试验的扭转接触面参数。
按用户最新说明，**不强制两指等位移，也不强行把轴夹持中心归零**。
保留原USD独立手指的实际接触结果；两指不对称程度作为诊断量记录，不作为失败判据。
`grasp_position_error.y=0`仅表示不额外采样Y方向初始误差，不代表接触后的Y偏移必须为零。


## 2. 抓取误差与孔估计误差

| 随机量 | 范围 | 坐标系与采样方式 |
|---|---|---|
| 抓取 x 偏差 | U[-8,+8] mm | panda_hand夹爪系，每回合独立均匀采样 |
| 抓取 y 偏差 | 恒为0 | 沿闭合方向不额外添加初始偏移 |
| 抓取 z 偏差 | U[-5,+5] mm | panda_hand夹爪系，每回合独立均匀采样 |
| 孔位置估计 x/y/z 偏差 | 每轴 U[-10,+10] mm | 固定件/世界平行坐标轴，每回合独立均匀采样 |

抓取误差实际作用到被夹轴的重置位置：

```text
shaft_reset_world = nominal_shaft_world + R_world_hand × grasp_offset_hand
```

使用与重置关节角对应的FK姿态做坐标变换，不把夹爪系Z误当世界系Z。
不额外增加轴姿态随机化。`y=0` 指采样偏差为0；名义抓取已有的小偏置及后续接触运动仍可能存在。

孔误差只污染孔的**估计位置**，**实际Base和hole_large在所有回合及reset时都保持固定**：

```text
estimated_hole = true_hole + hole_bias
```

同一回合的观测和控制始终使用同一份hole_bias，不在每帧跳变；奖励用真实几何和无噪力。
Actor不读取真实轴位姿、抓取偏差或hole_bias；critic可以使用这些特权信息。
局部reset只重采样对应环境，不修改其他环境的偏差。

## 3. 孔上方reset与残差动作

保留已求解的插入初态关节角，名义fingertip TCP约为 `(0.627, 0, 0.13) m`；
实际hole_large约为 `(0.627, -0.000182, 0.05) m`。
名义轴底在孔上方约19.3 mm，随后叠加用户要求的夹持误差。
不再使用此前Base的XY ±20 mm位置随机化，也不从取料点x=0.5 m开始。

控制点仍为由固定夹持标定得到的“名义轴底虚拟TCP”，不能随轴的真实滑移偷偷更新。

```text
phase = clip(max(t - 0.5 s, 0) × 8 mm/s / (19.3 mm + 47 mm), 0, 1)
nominal_xyz = estimated_hole + [0, 0, 19.3 mm - phase × 66.3 mm]
desired_xyz = nominal_xyz + [25 mm,25 mm,25 mm] × clip(action_xyz,-1,1)
```

最终目标仍按论文的λ限制到当前控制点附近，再由阻抗控制器生成力矩。
下插速度8 mm/s、xyz残差范围±25 mm是工程选择，可在参数类中修改；范围覆盖孔误差与抓取误差叠加。
残差是相对基准的有界偏移，**不逐步累加**。
零位置残差在夹持稳定后表示“执行基准下插”，不是原地保持。
若要保持，可以使用测试脚本的hold模式；训练中的策略可以用正Z残差退让、用XY残差搜索。

动作共5维：`[residual_x, residual_y, residual_z, yaw, success_prediction]`。
yaw相对于名义竖直姿态，范围±45°；第五维从[-1,1]映射到成功预测[0,1]。
Actor额外观察轨迹phase和夹爪总开口，便于区分不同下插阶段。
轨迹使用每个环境reset后的实际动作计时，不使用PPO可能随机初始化的episode计数；
因此训练启动时也不会跳过夹持稳定阶段或直接跳到轨迹中段。
