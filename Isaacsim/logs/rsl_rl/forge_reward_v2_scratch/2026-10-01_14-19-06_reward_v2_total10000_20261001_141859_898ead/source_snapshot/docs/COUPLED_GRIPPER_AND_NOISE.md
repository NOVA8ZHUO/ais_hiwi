# 两指耦合修复与delta噪声说明（2026-09-29）

用户确认真机两指等量耦合。此前允许两指独立位移不是应保留的真实抓取不对称，现已在Paper RL任务中修复。旧结果保留作历史，不与新物理模型混为一条性能曲线。

## 当前delta到底是什么

actor_state中：

```
delta_obs = p_virtual_TCP + epsilon - (p_true_hole + hole_bias)
epsilon_i ~ Normal(0, (0.00025 m)^2)
hole_bias_i ~ Uniform(-0.010 m, +0.010 m)
```

`p_virtual_TCP`由hand位姿与固定hand→标称轴底变换得到，不直接读取真实shaft轴底。真实轴底用于奖励、成功判定及诊断，不能把actor的delta称为准确的轴底−孔心差。

- 位置观测噪声：每轴标准差0.25 mm，约15 Hz每控制步新采样，同一步重复读取会缓存同一份样本。约95%落在±0.49 mm、约99.7%在±0.75 mm，但高斯噪声没有硬边界。位置差分得到的线速度观测也受此噪声影响。
- 孔估计偏差：XYZ各±10 mm，reset采样一次、回合内保持。真实base/孔不移动，偏差同时作用于孔估计观测与名义目标。
- 力观测另有每轴标准差1 N噪声，与位置delta不是同一项。

两种位置误差代表不同现象：逐步抖动可以被时间平均减弱，而外参/标定/一次定位的固定偏差不会因为多看几帧就消失。例如孔估计一直偏右8 mm，叠加0.25 mm测量抖动后仍平均偏右8 mm。

±10 mm是此前用户给出的任务误差范围，不是已测得的真机精度，也不是必须永远保持的常数。如果真机固定孔和标定能更准确定位，应根据测量减小这一分布；不要用0.25 mm白噪声假装覆盖毫米级固定偏差。此次未改任何噪声范围。

## 实际修复

原franka.usda兼容层删除了继承的mimic耦合，创建独立线性驱动，导致夹持中心存在额外自由度。新增franka_coupled.usda覆盖层，Paper任务引用它，以PhysX原生mimic约束实现：

```
q_finger2 - q_finger1 = 0
```

使用PhysxMimicJointAPI、gearing=-1、offset=0，referenceJoint指向finger1。单自由度棱柱关节由PhysX推断运动轴，rotX为schema实例标签（依据本机官方mimic测试/示例）。运行时不强行写回q或shaft姿态，不把零件固定到手上。

持续每指−20 N闭合、刚度0、速度阻尼200 N·s/m及闭合速度设置不变；成功后仍开爪。初始抓取X/Z误差、真实接触造成的零件滑移和旋转保留。两指等量运动不等于轴被刚性焊接。

归档加入assets/*.usda；trace补充Kp、deadzone、hole_bias、grasp_offset_hand和finger_difference，便于之后区分观测偏差与物理位移。

## 物理验证

两组均4环境、310控制步，零残差：

| 指标 | 无抓取/孔估计误差 | 完整随机误差 |
|---|---:|---:|
| 完成回合 | 8 | 4 |
| 成功并完成释放观察 | 8 | 0 |
| 超时 | 0 | 4 |
| 越界/夹宽失败 | 0/0 | 0/0 |
| 最大两指坐标差 | 0.0693 mm | 0.0670 mm |
| 夹持稳定后最大相对漂移 | 0.1566 mm | 0.2460 mm |
| 采样接触峰值 | 2.09 N | 5.92 N |

全部已记录的控制步smoke检查样本满足两指差<0.1 mm断言。约0.07 mm为数值求解残差，不能宣称浮点模拟里永远数学精确相等。以上零残差结果不是训练策略成功率；完整随机误差仍需要搜索纠偏。

数据位于`outputs/coupled_gripper/nominal*`和`randomized*`。独立的`test_gripper_coupling.py`验证单侧施力时两指仍等量移动、开爪与局部reset；该测试的宽度检查延迟30秒以允许主动测试开爪，不修改正式任务配置。

## 版本与后续
